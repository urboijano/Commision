# Contributing to KaonISU 🎉

Thank you for considering contributing! Here's how you can help.

## 🐛 Reporting Issues

- Search existing issues before opening a new one
- Include steps to reproduce, expected vs. actual behavior
- Attach screenshots or error logs if applicable

## 💡 Feature Requests

Open an issue with the **enhancement** label and describe:
- The problem you're solving
- How your proposal works
- Any alternative approaches considered

## 🔧 Pull Request Process

1. **Fork** the repository
2. **Create a branch**: `git checkout -b feature/your-feature` or `fix/your-fix`
3. **Make your changes** following the project's code style
4. **Test** your changes — ensure existing functionality still works
5. **Commit** with a clear, descriptive message
6. **Push** to your fork and open a PR against `main`
7. Wait for review — address any feedback if requested

## 🛠️ Development Setup

Refer to the [README](README.md#-getting-started) for setup instructions.

## 📐 Code Style

- Python: Follow [PEP 8](https://peps.python.org/pep-0008/)
- JavaScript: Standard vanilla JS conventions
- Templates: Indent with 4 spaces, keep logic minimal
- No commented-out code in PRs

## 🙋 Getting Help

Open a [discussion](https://github.com/urboijano/Commision/discussions) or issue if you have questions.
